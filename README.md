## 👋 Bienvenue

DB88 est un fichier HTML unique. Il affiche des sites web dans un cadre intégré. Vous organisez vos liens en dossiers, vous ajoutez ou supprimez des sites, et vous retrouvez votre historique. Tout est enregistré dans votre navigateur.

---

## ✨ Ce que vous trouverez

**Dossiers et sites personnalisables.**  
Vous créez des dossiers et vous ajoutez des sites avec un nom, une URL et une icône. Le mode édition permet de tout modifier ou réinitialiser.

**Ouverture dans un cadre intégré.**  
Les sites s'affichent directement dans la page. Si un site refuse l'intégration, un message clair s'affiche à la place.

**Historique local.**  
Les 200 derniers sites visités sont enregistrés. Vous pouvez rouvrir, supprimer une entrée ou tout effacer.

**Deux thèmes.**  
Un thème clair vert olive, un thème sombre. Le choix est mémorisé dans le navigateur.

**Écran de démarrage animé.**  
Un écran de démarrage avec barre de progression, journal de démarrage et effet CRT. Il peut être passé d'un clic.

**Barre de navigation.**  
Boutons Précédent, Suivant, Accueil, un champ d'URL et un bouton Historique.

---

## 🧭 Comment ça marche

**1. Ouvrez la page.**  
L'écran de démarrage s'affiche pendant six secondes, puis la page principale apparaît.

**2. Choisissez un dossier ou un site.**  
Les dossiers sont en haut. Les sites sont affichés dans une grille.

**3. Ajoutez ou modifiez un site.**  
Activez le mode « Edit », puis utilisez « + Site », « + Folder » ou les boutons de suppression.

**4. Naviguez librement.**  
Entrez une URL dans la barre ou choisissez un site. L'historique se remplit automatiquement.

C'est tout. Aucun compte n'est demandé.

---

## 🛠️ Petits coups de main

**Pourquoi certains sites ne s'affichent pas ?**  
Certains grands sites refusent l'intégration en cadre. C'est leur choix, pas un bug de DB88.

**Où sont enregistrés mes dossiers et mon historique ?**  
Dans le stockage local de votre navigateur, sur votre appareil uniquement.

**Puis-je utiliser DB88 hors ligne ?**  
Seulement après le premier chargement. La page elle-même fonctionne hors ligne, mais les sites visités nécessitent une connexion.

**Puis-je réinitialiser mes dossiers ?**  
Oui. En mode « Edit », le bouton « Reset » restaure les dossiers par défaut sans effacer l'historique.

## 👋 Welcome

DB88 is a single HTML file. It displays websites inside an embedded frame. You organize your links into folders, you add or delete sites, and you find your history. Everything is saved in your browser.

---

## ✨ What you'll find

**Customizable folders and sites.**  
You create folders and add sites with a name, a URL and an icon. Edit mode lets you modify or reset everything.

**Opening inside an embedded frame.**  
Sites are displayed directly in the page. If a site refuses embedding, a clear message appears instead.

**Local history.**  
The last 200 visited sites are recorded. You can reopen, delete one entry, or clear them all.

**Two themes.**  
A light olive-green theme, and a dark theme. The choice is remembered in the browser.

**Animated boot screen.**  
A boot screen with a progress bar, a boot log and a CRT effect. It can be skipped with one click.

**Navigation bar.**  
Back, Forward, Home buttons, a URL field and a History button.

---

## 🧭 How it works

**1. Open the page.**  
The boot screen runs for six seconds, then the main page appears.

**2. Pick a folder or a site.**  
Folders are at the top. Sites are shown in a grid.

**3. Add or edit a site.**  
Turn on "Edit" mode, then use "+ Site", "+ Folder", or the delete buttons.

**4. Browse freely.**  
Enter a URL in the bar or pick a site. History fills in automatically.

That's it. No account is required.

---

## 🛠️ A little help

**Why do some sites not display?**  
Some large sites refuse embedding in a frame. That's their decision, not a bug in DB88.

**Where are my folders and history saved?**  
In your browser's local storage, on your device only.

**Can I use DB88 offline?**  
Only after the first load. The page itself works offline, but visited sites need a connection.

**Can I reset my folders?**  
Yes. In "Edit" mode, the "Reset" button restores the default folders without clearing history.
